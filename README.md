# SUZSHOP
Crée un site e-commerce féminin, luxueux et responsive. Prévois un espace client et un espace administrateur sécurisé (code initial : Samuella12). L'admin peut choisir le nom, le logo, gérer les produits, prix, stocks et livraisons. Intègre Airtel Money (076326698) et Moov Money (066099994). Interface simple et professionnelle.
